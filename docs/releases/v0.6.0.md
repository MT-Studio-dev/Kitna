# Kitna v0.6.0

Kitna keeps its existing Manga Panels theme and makes Light the default. The supplied screenshots guide the placement of options: Groups first, compact expense rows, group settings and expandable member balances.

## Changes

- Copy a short group code from a newly shared group or its settings. Friends enter it through Groups → Join group. Codes last seven days and can be revoked.
- Ask for an optional Google email when adding a friend. Verified matching Google accounts automatically join email-invited groups during synchronization, using the existing participant and balances. No email message is sent.
- Add clearer group settings, members, invitations and leave controls. Owners can leave once another joined account can take ownership.
- Organize Account settings and expose logout for signed-in users.
- Add optional shared-activity notifications through Account → Settings → Notifications. Foreground alerts follow synchronization. Android schedules background checks roughly every 15 minutes or later; this is not instant push delivery. Own edits and first-sync history stay silent.
- Retain the original colors, artwork and saved appearance choices. Light applies when no preference has been saved.

## Install or update

Install `Kitna-0.6.0.apk` over your existing Kitna app. Do not uninstall it to update. The application ID and established development signing certificate are unchanged, so normal updates keep the database and receipt files. Keep a complete exported backup when changing phones or reinstalling.

## Backend and verification

Both migrations are installed in the configured Supabase project; hosted preflight confirms protocol 2. Other installations should apply `202611240001_shared_groups.sql`, followed by `202611240002_invitation_codes.sql`, and run the verification queries.

129 tests passed (52 core + 77 Android JVM), along with 31 separate PostgreSQL tests. Assembly passed; lint reported 0 errors and 33 warnings. Light/default appearance and the revised layout were rendered and reviewed.

This is a development-signed preview. Real-device Google consent, two-phone expense/receipt synchronization, background notification delivery and TalkBack still need verification before a production launch.
