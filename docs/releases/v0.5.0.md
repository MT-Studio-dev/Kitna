# Kitna v0.5.0

Kitna by MT Studio adds the Manga Panels design and optional shared groups so friends can record expenses from their own phones.

## What's included

- Manga Panels light and dark themes, stronger colors for large expenses, and budget colors with readable status labels.
- Google sign-in, group invitations, shared expenses and repayments, private receipts, offline drafts, and conflict review.
- First-run guidance, faster expense entry and duplication, accessibility improvements, and Help and About screens.
- MT Studio artwork, GitHub profile, and support contact.
- Receipt photos, trip budgets, shareable trip summaries, and complete ZIP backups introduced since the previous repository version.
- Existing-record preservation during normal updates using the same application ID and signing certificate.

## Install or update

Download `Kitna-0.5.0.apk` from this release and install it over the existing Kitna app. Keep a complete exported backup before updating. This APK uses the established development signing identity; it is a preview build, not a Play Store production package.

Do not uninstall Kitna to update it: uninstalling removes the device's local records and receipt files. Google sign-in and shared-group synchronization require internet; local tracking remains available offline.
