# Kitna v0.7.1 — palette, settlement and invitation fixes

## Changes

- Adjusted expense rows for narrow screens and enlarged text so descriptions and amounts remain readable. Non-group history also namespaces month sections across friend ledgers.
- Removed the visible "Large expense" caption. Larger bills use a stronger amount size/weight and subtle row tint instead.
- Replaced brown, cream and gold base colors with paired indigo/slate themes: cool light surfaces, navy dark surfaces, teal positive balances and rose negative balances. Category accents and avatars follow the cooler palette. Original artwork, Manga typography and explicitly chosen group colors remain intact.
- Simplified Settle up to a compact context, tappable payer/recipient and prominent INR amount. Payment method, date, reference and delete are under More options. Existing debt context supplies sensible defaults; a friend repayment does not require creating a visible group.
- Preserved draft/discard behavior and added repeated-save protection, atomic friend-ledger repayment creation, and original-version checks for shared repayment edits/deletes.
- Corrected the hosted invitation mismatch after explicit production authorization: the installed Android build expected protocol-3 friend/invitation functions while the server still ran protocol 2. The prepared migration was applied to the Kitna production project on 28 November 2026.

## Production invitation update

The exact approved `202611250001_simplified_collaboration.sql` migration completed successfully. `kitna_status` now reports protocol 3, and all 11 deployment checks pass. Counts were unchanged across deployment: 5 groups, 12 participants, 26 records, 8 revisions and 2 receipt metadata records. No reset, financial-history rewrite or receipt deletion was performed.

This resolves the absent functions that caused Add friends → Invite and Share invite link to show "This feature needs a Kitna service update." The installed v0.7.0 app can retry those actions against the upgraded service; the new APK provides the palette, expense and settlement changes.

The hosted security advisor reported 0 errors, 22 warnings and 7 suggestions. Intentional authenticated security-definer RPCs still require their explicit backend authorization checks. Public endpoint availability checks and Google provider/anonymous-access preflight are separate from a real two-account phone test.

Install `releases/Kitna-0.7.1-dev.apk` over the existing Kitna app. Application ID `app.kitna`, the established development signing key, Room schema 1 and stored records remain compatible. Version code is 8.
